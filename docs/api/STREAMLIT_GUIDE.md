# 🌐 Streamlit 看板使用手册

> Streamlit Web 看板功能分区说明、操作流程与配置指南。

---

## 1. 快速启动

```bash
# 进入项目目录
cd fin-research-agent

# 确保已初始化数据
python init_data.py

# 启动 Streamlit
streamlit run app.py --server.port 8501

# 浏览器打开
# http://localhost:8501
```

### 1.1 系统要求

- Python >= 3.10
- 浏览器:Chrome / Edge / Firefox(最新版)
- 屏幕分辨率:建议 >= 1366×768
- 网络:可访问通义千问 API

## 3. 功能页面详解

### 3.1 📝 投研分析(主页)

**功能**:输入自然语言问题,生成完整投研报告 + 可视化图表。

**页面布局**:

```
┌───────────────────────────────────────────────────┐
│  💬 请输入你的投研问题...                            │
│  ┌─────────────────────────────────────────────┐  │
│  │ 分析茅台2023年财报,对比行业,引用研报...       │  │
│  └─────────────────────────────────────────────┘  │
│                                                    │
│  [分析模式: 自动 ▾]  [包含图表: ✅]  [分析] 按钮    │
├───────────────────────────────────────────────────┤
│  ⏳ 正在分析...(进度/流式输出)                       │
│                                                    │
│  📌 贵州茅台(600519)投研分析报告                    │
│  ───────────────────────────────                   │
│  一、财务表现速览                                   │
│  ...                                               │
│                                                    │
│  [图表区域]                                        │
│  ┌─────────────────────────────────────────────┐  │
│  │  茅台 vs 行业平均 ROE 对比柱状图              │  │
│  │  (Plotly 交互式图表)                         │  │
│  └─────────────────────────────────────────────┘  │
│                                                    │
│  📎 数据来源                                       │
│  • SQL 查询: SELECT ...                            │
│  • 研报引用: 3 份文档                              │
└───────────────────────────────────────────────────┘
```

**操作流程**:
1. 在输入框中输入你的投研问题
2. 选择分析模式(自动/SQL/文档/混合)
3. 勾选是否需要可视化图表
4. 点击「分析」按钮或按 Ctrl+Enter
5. 等待生成,报告将流式逐字显示
6. 查看下方的图表和数据来源

**示例问题**(直接复制可用):
- `茅台近5年营收复合增长率是多少?`
- `白酒行业平均ROE是多少?对比一下各公司`
- `分析宁德时代的财务状况,有没有相关研报?`
- `新能源行业有哪些股票?市值排名如何?`

## 4. 左侧边栏

### 4.1 系统状态

实时显示各组件连接状态:
- 🟢 **LLM** — 通义千问 API 连接状态
- 🟢 **数据库** — SQLite 连接状态
- 🟢 **向量库** — FAISS 索引加载状态
- 📊 **文档数** — 已索引文档总数
- 📊 **Chunk 数** — 向量索引 chunk 总数

### 4.2 设置(部分可实时调整)

| 设置项 | 说明 | 实时生效 |
|--------|------|---------|
| 模型选择 | qwen-turbo / qwen-plus / qwen-max | ✅ |
| Temperature | LLM 创造性(0-1) | ✅ |
| Top-K | RAG 召回数量 | ✅ |
| 主题 | 亮色 / 暗色 | ✅ |
| 流式输出 | 是否开启流式 | ✅ |

## 5. 常见操作

### 5.1 调整主题

右上角 → 设置 → 主题 → 选择「亮色」或「暗色」

### 5.2 导出报告

投研分析页面 → 报告区域右上角 →「📥 导出 Markdown」按钮

### 5.3 清空缓存

左侧边栏 → 系统状态 →「🗑️ 清空缓存」按钮

## 6. 配置项

### 6.1 Streamlit 相关环境变量

| 配置项 | 默认值 | 说明 |
|--------|-------|------|
| `STREAMLIT_PORT` | 8501 | Web 看板端口 |
| `STREAMLIT_THEME` | light | 默认主题: light / dark |

### 6.2 启动参数

```bash
# 指定端口
streamlit run app.py --server.port 8501

# 指定主题
streamlit run app.py --theme.base dark

# 关闭自动重载
streamlit run app.py --server.headless true
```
